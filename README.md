## 🇵🇹 Português

Ferramentas e projetos pessoais na interseção entre dados, energia e sistemas — desenvolvidos e mantidos de forma independente.

O nome refere-se a três correntes: elétrica, oceânica, de dados. Ponto de partida comum para projetos que, de outra forma, não têm muito em comum entre si além de quem os escreve.

### Projetos

#### [NDC_Tools](https://github.com/CorrenteLabs/NDC_Tools)
Conjunto de ferramentas para trabalhar com mensagens NDC (New Distribution Capability) da IATA, cobrindo as versões de standard 18.1 e 21.3. Inclui validação, parsing e apoio a testes de integração com parceiros de distribuição aérea.

#### [Solar Dashboard](https://github.com/CorrenteLabs/solar-dashboard)
Dashboard de monitorização de sistema solar residencial, integrando produção fotovoltaica, armazenamento em bateria, veículos elétricos e arbitragem tarifária. Extração de dados automatizada e histórico multi-período.

## 🇬🇧 English

Personal tools and projects at the intersection of data, energy, and systems — developed and maintained independently.

The name refers to three currents: electrical, oceanic, and data. A shared starting point for projects that, otherwise, don't have much in common besides who writes them.

### Projects

#### [NDC_Tools](https://github.com/CorrenteLabs/NDC_Tools)
A set of tools for working with IATA NDC (New Distribution Capability) messages, covering standard versions 18.1 and 21.3. Includes validation, parsing, and support for integration testing with airline distribution partners.

#### [Solar Dashboard](https://github.com/CorrenteLabs/solar-dashboard)
A monitoring dashboard for a residential solar system, integrating photovoltaic production, battery storage, electric vehicles, and tariff arbitrage. Automated data extraction and multi-period history.
