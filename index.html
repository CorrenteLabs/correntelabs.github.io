A marca

Sem empresa, sem produto — só a assinatura de quem escreve

Corrente Labs reúne projetos pessoais construídos fora do horário de trabalho, para resolver problemas concretos onde não existiam soluções prontas. Não é uma empresa nem uma marca comercial — é o ponto de partida comum entre projetos que, de outra forma, não teriam nada em comum entre si.

Cada projeto é entregue como uma aplicação HTML autónoma, sem servidor e sem dependência de terceiros para funcionar — os dados que processam nunca saem do browser de quem os usa.

NDC Tools

v1.3.5

Parsing e visualização de respostas IATA NDC 18.1

Cinco ferramentas integradas para trabalhar mensagens NDC (New Distribution Capability): mapas de lugares interativos, comparação de ofertas, serviços ancilares e o detalhe completo de uma reserva. Tudo processado localmente — nenhum XML sai do computador.
